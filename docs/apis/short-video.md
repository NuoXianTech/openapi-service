# 短视频解析接口

`GET /v1/short-video` 解析受支持平台的短视频、图集或实况分享链接。`url` 参数可以是分享链接，也可以是包含链接的完整分享文案，最长 4096 个字符。

支持抖音、快手、小红书、哔哩哔哩、微博、皮皮虾、皮皮搞笑和今日头条/西瓜视频。成功时 JSON 使用标准响应壳，`data` 统一包含平台、媒体类型、作者、标题、封面、视频、图片、实况和音乐字段。

Service 只访问各平台的固定 HTTPS 域名。每次请求和每一跳重定向都会重新校验域名、端口和 DNS 地址，阻止内网、环回、链路本地、保留地址与 DNS 重绑定；上游文本响应限制为 4 至 8 MiB，并受 Service 请求截止时间约束。接口不会把输入地址当作任意代理目标。

分享内容不存在、失效或无法解析时返回稳定的 `422`；平台限流返回 `503` 并在上游提供时携带 `Retry-After`。响应不缓存。
