# QQ 头像接口

`GET /v1/qq-avatar` 生成指定 QQ 号的腾讯官方头像地址。

| 参数 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `qq` | 是 | - | 5 至 12 位且不以 `0` 开头的 QQ 号 |
| `size` | 否 | `100` | `40`、`100`、`140` 或 `640` |
| `type` | 否 | `json` | `json` 或 `image` |

JSON 模式返回标准响应壳；`image` 模式返回 `302`，客户端直接访问 `q1.qlogo.cn`，不消耗 Service 图片带宽。接口只生成固定腾讯域名的地址，不接受任意目标，也不代理图片内容。成功响应允许客户端缓存一天。
