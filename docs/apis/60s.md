# 每日 60 秒公共接口

`GET /v1/60s` 获取“每天 60 秒读懂世界”的新闻摘要和每日微语。Service 从 `60s-static.viki.moe` 读取静态数据，并在该来源不可用时回退到 `vikiboss/60s-static-host` 的 GitHub 原始文件。

该端点属于受信 Service 接口，只接受 Platform 注入的 `Authorization: Service <token>`，不应直接暴露到公网。调用方 API Key、积分、限流和统计由 Platform Route 管理。

## 请求参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `date` | 上海时区的当天 | 严格的 `YYYY-MM-DD` 日期；省略时若当天尚未更新，最多向前回退两天 |
| `encode` / `encoding` | `json` | `json`、`text`、`markdown` 或 `md` |

默认 JSON 返回统一响应壳，`data` 包含日期、新闻列表、封面、每日微语、原文链接、上游创建/更新时间、星期和农历日期。`text` 与 `markdown` 返回对应的原始文本表示。

## 缓存与边界

- Service 按实际内容日期在进程内缓存 30 分钟，最多保留 64 个日期，避免任意日期请求无限占用内存。
- 成功响应设置 `Cache-Control: public, max-age=900`。
- 每个固定来源最多等待 8 秒，响应正文上限为 256 KiB，禁止跟随重定向。
- 只保留 `https` 且不含凭据和非标准端口的封面与原文链接。
- 默认测试使用本地响应 Fixture，不访问真实第三方网络。

日期无效返回 `400 INVALID_DATE`，输出格式无效返回 `400 INVALID_ENCODING`，来源不可用、内容不存在或数据结构错误返回 `502 UPSTREAM_ERROR`。
