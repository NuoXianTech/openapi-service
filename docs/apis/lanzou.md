# 蓝奏云链接解析接口

`GET /v1/lanzou` 解析单个蓝奏云文件分享链接，支持公开文件和带分享密码的文件，不支持文件夹。

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `url` | 是 | 蓝奏云 HTTPS 单文件分享链接 |
| `pwd` | 否 | 分享密码 |
| `type` | 否 | `down` 时返回 302，否则返回 JSON |

JSON 使用 Service 标准响应壳，`data` 包含文件名、大小和短期有效的上游下载地址。所有响应使用 `Cache-Control: no-store`。`type=down` 只跳转，不通过 Service 代理文件内容。

Service 仅接受受支持的蓝奏域名，禁止用户信息、非标准端口和文件夹链接。解析时优先保留分享链接的原始蓝奏域名，以兼容与域名绑定的风控 Cookie；旧域名因证书或网络问题无法安全连接时，才回退到 `www.lanzouf.com`。遇到阿里云 `arg1` 挑战页时，会计算 `acw_sc__v2` 并使用相同 User-Agent 和 Referer 重试。`pwd` 会原样传给蓝奏云，不会裁剪或写入错误响应。

解析器兼容 `ajaxm.php` 与新版 `ajaxfile.php`、公开 iframe、带查询参数页面和密码文件。页面与 JSON 均有大小限制，所有跳转逐跳校验 HTTPS、官方域名、DNS 和公网地址。解析结果会尝试取得最终直链；若最终跳转不可用或不可信，则回退到已经验证的蓝奏下载地址。内部 `pid` 参数会从返回地址中移除。

实现参考 `LanzouAPI` 1.3.108 的解析流程，但不会关闭 TLS 验证、伪造客户端 IP 或允许无约束跳转。

输入问题返回 `400`，失效分享、密码错误或页面结构变化返回 `422`，不可信或无效上游响应返回 `502`。错误响应不会回显分享密码。
